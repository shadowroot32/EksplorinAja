# 1. Anatomi Kloroplas dan Aliran Elektron Fotosintesis

Fotosintesis berlangsung di organel kloroplas dengan dua tahapan berangkai: Reaksi Terang di membran tilakoid dan Reaksi Gelap (Siklus Calvin) di stroma. Fotolisis air pada Fotosistem II ($2H_2O \rightarrow 4H^+ + 4e^- + O_2$) menghasilkan gradien proton untuk sintesis ATP oleh ATP Sintase.

Catatan Kritis Pengujian: Enzim RuBisCO mengkatalisis fiksasi $CO_2$ pada fase karboksilasi Siklus Calvin. Setiap fiksasi 3 molekul $CO_2$ menghasilkan 1 molekul G3P bersih dengan konsumsi 9 ATP dan 6 NADPH.

Frequently Asked Questions

Apakah Cendekia.ai benar-benar 100% gratis?
Ya, 100% gratis selamanya tanpa batasan kuota token, tanpa paywall, dan tanpa perlu kartu kredit. Sistem ini berjalan mandiri di Proxmox VM lokal dengan dukungan LLM lokal.
Bagaimana cara kerja Spaced Repetition (SM-2)?
Algoritma SuperMemo-2 (SM-2) memprediksi kurva lupa otak manusia. Berdasarkan rating Anda (Again, Hard, Good, Easy), sistem secara matematis menghitung interval optimal hari berikutnya kapan kartu tersebut harus diulas kembali.
Bisakah video materi diekspor langsung ke format MP4?
Bisa! Server Cendekia.ai dilengkapi dengan pipeline visual Pillow dan FFmpeg yang merender slide presentasi dan suara narasi menjadi file MP4 offline (pilihan format landscape 16:9 untuk laptop atau portrait 9:16 Shorts untuk smartphone).
Bagaimana cara menghubungkan Cendekia.ai dengan Claude AI?
Klik tombol "Claude MCP" di navigasi atas untuk mendapatkan URL endpoint Streamable HTTP atau Server-Sent Events (SSE). Masukkan URL tersebut ke konfigurasi Custom Connector Claude Web atau Claude Desktop.
